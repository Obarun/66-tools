execl-toc

Tests an element and creates it if it not exist yet with default or specified options, then executes a program by default.

Interface

	execl-toc [ -h ] [ -v verbosity ] [ -D ] [ -X ] [ -d|p|S|m|L|e|b|c|k|n|g|r|s|t|u|w|x|f|z|O|U|N|V|E element ] [ -o opts ] [ -t type ] [ -d device ] [ -g gid ] [ -u uid ] [ -m mode ] [ -s|D|B|b ] [ -b backlog ] prog
  • Execl-toc (test or create) tests an element and creates it if it not exist yet where element can be a directory, a fifo,a socket,a mountpoint for test and creation and a file and a string for a test only. Then it execs into prog..., i.e. the rest of its command line.
    The options are separated in three parts: main_options, test_options and create_options and must ordered at the command line in that way.
    The creation of a element can be controlled with the helps of create_options options. Some of these create_options are specific for a particular element where others are general.

Main options

Main_options are not mandatory.

  • -h  : prints this help.
  • -v verbosity  : increase/decrease verbosity. Default is 0 meaning nothing is printed except for fatal errors.
  • -D  : performs the test without creating the element if it not exist yet.
  • -X  : do not execute prog.

Test options

Test_options are mandatory and must precede the create_options. Parent directories of element will also created at creation process if it doesn't exist with 0755 as permissions if -m is not specified.

    Test and create:

    • -d  : true if element is a directory.
    • -p  : true if element is a fifo.
    • -S  : true if element is a socket.
    • -m  : true if element is a mountpoint.
    • -L  : true if element is a symlink.

    Test only

    • -e  : true if element exist.
    • -b  : true if element is a block.
    • -c  : true if element is a character.
    • -k  : true if sticky bit is set for element.
    • -n  : true if the length of element is non-zero.
    • -g  : true if element is set-group-id.
    • -r  : true if element is readable.
    • -s  : true if the size of element is greater than zero.
    • -t  : true if element is open and refer to a terminal.
    • -u  : true if set-user-id bit is set for element.
    • -w  : true if element is writable.
    • -x  : true if element is executable.
    • -f  : true if element is a regular file.
    • -z  : true if the length of element is zero.
    • -O  : true if element is owned by the effective user id.
    • -U  : true if element is owned by the effective group id.
    • -N  : true if element has been modified since it was last read.
    • -V  : true if element exit on the environment.
    • -E  : true if element is an empty directory. The test performs check of an existing block, character, fifo, regular file, directory, symlink inside element.

Create options

Depending of the element to create, create_options may or may not mandatory. The following explanation specify the mandatory ones.

  • -o opts  : mount options (correspond to mount -o). Mandatory is case of mountpoint creation. This option has no effect in other case.
  • -t type  : type mount options (correspond to mount -t). This also used in case of symlink creation as target option. Mandatory is case of mountpoint or symlink creation. This option has no effect in other case.
  • -d device  : device mount options (correspond to mount -t type device /directory). Mandatory is case of mountpoint creation. This option has no effect in other case.
  • -u uid  : changes element's owner to (numeric) uid after the creation. Default is the uid of the owner of the process. This options is used for directory and fifos creation and its has no effects in other cases.
  • -g gid  : changes element's owner to (numeric) gid after the creation. Default is the gid of the owner of the process. This options is used for directory and fifos creation and its has no effects in other cases.
  • -m mode  : create element owner to (numeric) gid after the creation. Default is 0755, 0666 and 0777 for a directory, fifo and socket creation respectively. This options is used for directory, fifos and sockets creation and its has no effects in other cases.
  • -s  : element will be SOCK_DGRAM where element is a socket. Default SOCK_STREAM. This options is used for socket creation and its has no effects in other cases.
  • -D  : disallow instant rebinding at element to the same path where element is a socket. Default allow. This options is used for socket creation and its has no effects in other cases.
  • -B  : the element will be blocking where element is a socket. Default unlocked. This options is used for socket creation and its has no effects in other cases.
  • -b backlog  : set the maximum of backlog connection on the element where element is a socket. Default SOMAXCONN. This options is used for socket creation and its has no effects in other cases.

Exit codes

  • 0   : success.
  • 110  : bad usage.
  • 111  : system error.

Usage examples

Test and create a directory if it doesn't exist yet:

		#!/usr/bin/execlineb -P
		execl-toc -d /run/user/1000 -m 0700
		66-echo -- "/run/user was created"

Test a directory but do not create it if it doesn't exist:

		#!/usr/bin/execlineb -P
		execl-toc -D -d /run/user/1000
		66-echo -- "/run/user already exist"

Test a directory, do not create if it doesn't exit and do not execute prog

		#!/usr/bin/execlineb -P
		if -n { execl-toc -X -D -d /run/user/1001 }
		66-echo -- "/run/user/1001 doesn't exist"

Test a mountpoint and create it if it doesn't exist

		#!/usr/bin/execlineb -P
		execl-toc -m /dev/hugepage -o noatime,nodev,noexec,nosuid -t hugetlbfs -d hugepages
		66-echo -- "/dev/hugepage created and mounted successfully"

Test a socket create it if it doesn't exist

		#!/usr/bin/execlineb -P
		execl-toc -S /run/user/dbus
		66-echo -- "you can now use the socket"

Test if a variable is set on the environment

		#!/usr/bin/execlineb -P
		execl-toc -V PATH
		66-echo -- "PATH variable is set"

Test if a file exit

		#!/usr/bin/execlineb -P
		execl-toc -e /home/obarun/.xinitrc
		66-echo -- ".xinitrc is a regular file"

Test if a file is executable 

		#!/usr/bin/execlineb -P
		execl-toc -x /home/obarun/.xinitrc
		66-echo -- ".xinitrc is a regular file"

Test if a directory is empty 

		#!/usr/bin/execlineb -P
		execl-toc -x /mnt
		66-echo -- "/mnt is emtpy"
